# 管理后台默认交付清单

> 适用：时叙运营台/总部后台、在场 PC 后台，以及后续门店工作台。  
> 规则：**默认全做**；不适用写“N/A + 原因”。后台不是“能点就行”，它直接改钱、货、权限和账。

## 0. 最容易漏的十项

- [ ] 角色导航与四维权限（身份 × 动作 × 对象范围 × 字段范围）
- [ ] 门店/组织范围；ALL/NONE/具体集合分开
- [ ] 列表的服务端分页、筛选持久化、空/错/载
- [ ] 危险操作二次确认、原因、审计
- [ ] 提交的幂等键与成功后回读
- [ ] 配置入口（价格、库存、退款门槛、门店能力、排序）
- [ ] 财务台账 append-only、历史月不改
- [ ] 营业台草稿 TTL、账号/门店隔离、会员码不落 storage
- [ ] 图表悬停具体值、空数据不造假
- [ ] 部署后 `prisma generate`、健康检查、静态资源校验

## 1. 开项前

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 权威工程 | 确认 admin/server 当前目录与分支；旧 demo 不作交付 | 路径 + 提交 |
| □ | 角色清单 | 列出总部、财务、店长、店员、只读等角色及能做什么 | 角色 × 页面矩阵 |
| □ | 数据范围 | 确认门店/部门/区域层级；不存在就不硬建 | 范围模型 |
| □ | 设计基线 | 沿用现有后台设计系统；不把小程序视觉搬进 PC | token 来源 |
| □ | API 契约 | 分页、筛选、金额单位、枚举、错误码先定 | 契约表 |
| □ | 测试数据 | 隔离库/合成门店与订单；不碰生产 | 环境变量/DB 路径 |

## 2. 信息架构与权限

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 导航 | 按角色分组，不把无权菜单只靠隐藏；直接访问 URL 也要拦 | 用无权账号直连 |
| □ | 四维权限 | 身份 × 动作 × 对象范围 × 字段范围；列表/详情/导出/批量都一致 | 直接 HTTP 正反用例 |
| □ | 范围表达 | ALL / NONE / 门店集合分开；空授权不默认全量 | 零门店账号 |
| □ | 字段可见 | 成本、供货价、内部备注按权限返回；前端隐藏不算 | DTO 检查 |
| □ | 越权 | 账号 A 操作账号 B/门店 B 的对象必须拒绝 | 绕过前端发请求 |
| □ | 批量/导出 | 与列表同范围；导出内容与筛选标题一致 | 导出抽查 |
| □ | 审计 | 谁、何时、对什么、改前/改后、原因 | 日志页/DB |

## 3. 布局与响应式

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 侧栏 | 桌面 196px；≤900px 图标态；品牌在侧栏，不额外加顶部横栏 | 1440/1280/768 截图 |
| □ | 内容区 | 从视口顶部开始；粘性工具条 offset 与侧栏一致 | DOM 几何 |
| □ | 表格密度 | 1280/1440 一屏可见关键列；不横向溢出主操作 | 两档截图 |
| □ | 营业台 | 平板横屏可用；点单、购物袋、收款同屏 | 1024/1280 |
| □ | 弹窗 | 用现有 Dialog/Drawer；长表单用抽屉；说明入口可关闭 | 真实点击 |
| □ | 移动端 | 至少不崩、不遮挡；后台不承诺手机全功能 | 390 宽抽查 |

## 4. 列表、筛选与导出

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 分页 | 服务端分页；超过边界仍有总计/下一页 | 造 >1 页数据 |
| □ | 筛选 | 类型/门店/状态/日期；非法区间回默认；按页持久化 | 刷新后保留 |
| □ | 空/载/错 | 三态分开；失败不显示 0；旧数据标注时间 | 断网/500 |
| □ | 排序 | 服务端排序；总部默认 + 门店覆盖时写清优先级 | 改序后两端一致 |
| □ | 导出 | 与当前筛选一致；大数据量异步/上限提示 | 导出抽查 |
| □ | 关键词 | 明确搜索字段；不把前端过滤冒充全量搜索 | 造边界数据 |

## 5. 表单与危险操作

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 校验 | 必填、长度、金额、日期、枚举；服务端再校验 | 负向用例 |
| □ | 脏数据 | 离开未保存提示；恢复草稿要说明来源 | 真机/浏览器 |
| □ | 确认 | 删除、取消、退款、清空、停业二次确认；写清后果 | 真实点击 |
| □ | 原因 | 退款/报损/改价/关账等要原因或备注 | 审计可见 |
| □ | 幂等 | 提交带稳定幂等键；重复点击不产生第二单 | 连点/重试 |
| □ | 成功回读 | 保存后重新请求确认；不以前端 toast 当成功 | 刷新后仍在 |
| □ | 缓存 | 部署后旧标签页可能打旧 bundle；提示硬刷新或版本号 | 旧页面操作 |
| □ | 错误 | 409/400 给可读原因；不把业务拒绝包成 500/503 | 接口探针 |

## 6. 配置与运营

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 必配项 | 门店/营业状态、商品价格/可售/选项/描述/排序、库存、退款门槛、会员权益、报损、设备、通知模板、财务分类 | 后台入口清单 |
| □ | 范围继承 | 总部默认 → 门店覆盖；不存在区域层就不建 | 改总部/门店各一次 |
| □ | 版本/生效 | 生效时间、版本、历史订单用快照还是新值 | 改价后旧单 |
| □ | 权限 | 谁能改、谁能看；配置变更写审计 | 角色测试 |
| □ | 缺值 | 缺配置 fail-closed；不导致免费、全权限、假成功 | 删配置测试 |
| □ | 常量 | 品牌/协议/换算可留代码；经营规则必须可配 | 说明理由 |

## 7. 交易、财务与对账

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 台账 | append-only；退款用负数冲减，不改历史 | 退款后查流水 |
| □ | 月度关账 | OPEN/CLOSED；自动关账时间；历史月不动 | 跨月测试 |
| □ | 快照 | 成交价、优惠、商品选项、成本口径入快照 | 改配置后旧单 |
| □ | 退款 | 占用/处理中/成功/失败/未知；失败释放，未知保留 | 退款矩阵 |
| □ | 对账 | 渠道流水、本地流水、订单状态可追踪；差异有凭证 | 一笔真实/沙箱 |
| □ | 报表 | 时间/金额/归属口径统一；重复消息不重复记账 | 重放回调 |
| □ | 权限 | 成本/利润/供货价按字段授权 | 无权限账号 |

## 8. 营业台（POS）

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 草稿 | key 含 storeId + staffId；TTL 90 分钟；成功/退出清理 | 两人两店互不串 |
| □ | 会员码 | 绝不入 localStorage；恢复后重新核验 | storage 检查 |
| □ | 扫码 | 扫码枪常驻时全局按键接管；输入框聚焦时不误触 | 真机/浏览器 |
| □ | 收款 | 现金/付款码反扫/正扫按渠道能力显示；不显示不可用方式 | 渠道 live/mock |
| □ | 支付 | 未支付不打印杯贴；回调/查询确认后才算收款 | 假付款码/1 分 |
| □ | 退款 | 二次确认、原因、占用释放、可重试 | 真机 |
| □ | 出餐 | 待制作/待取餐分栏；扫码/确认出餐幂等 | 连扫两次 |
| □ | 离线 | 断网提示；不假装成功；恢复后可重试 | 断网 |

## 9. 视觉、图表与文案

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | token | 沿用后台设计系统；不混用小程序色 | 源文件 |

## 10. 状态与异常

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 401/403 | 401 回登录；403 说明无权限；不显示空白页 | 直连 URL |
| □ | 409 | 并发/重复操作给可读冲突提示 | 双开操作 |
| □ | 500 | 不暴露堆栈；有请求 ID/日志 | 故障注入 |
| □ | 超时 | 不自动重试写操作；提示结果未知并可查 | 断网 |
| □ | 旧数据 | 标注时间/条件；筛选与导出一致 | 混合数据 |
