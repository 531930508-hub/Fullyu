# 现金单退款失败修复（2026-11-23）

## 背景

2026-11-22 21:24 门店报「订单退款报错，无法退款」。订单是营业台现金收款
（`paymentMethod=cash`，`paymentRef` 是 `PAY-…` 流水号），点「退款」后金额没退，
订单停在已支付。

## 根因

`OrdersService.refund` 在占用退款额度后，无条件调用 `runGatewayRefund`，用
`order.paymentRef` 去汇付「原路退回」。现金单没有渠道交易，汇付返回
`原交易不存在 / 原交易查询失败`；`onError` 把占用释放，退款状态回到未退款，
接口 400，钱不可能到账——代码路径本身就把线下现金当成了线上支付。

## 改动（`main@1397d4a`）

| 文件 | 改动 |
|---|---|
| `apps/server/src/orders/refund-channel.ts`（新增） | `refundChannelOf`：按 `paymentMethod` 判 `cash`/`gateway`；`paymentRef` 以 `CASH-` 开头的历史单兜底为现金 |
| `apps/server/src/orders/orders.service.ts` | `runGatewayRefund` → `runRefund`：现金单跳过网关，直接确认落账（可退数量、库存回补、成本与财务流水口径不变），直退/审批通过/失败重试全部走同一入口；返回 `channel` |
| `apps/server/src/approvals/approvals.service.ts` | 审批结果按渠道写「已登记现金退款 ¥X，请门店将现金交还顾客」 |
| `apps/admin/src/lib/api.ts`、`pages/StoreApp.tsx`、`pages/AdminApp.tsx` | 退款弹窗按现金单显示「确认现金退款」「系统只登记，钱请当面交还顾客」；`storeRefund` 返回 `channel` |
| `apps/miniprogram/src/pages/legal/index.vue` | 会员条款退款段补充「现金支付由门店当面退还」 |
| `apps/server/src/orders/refund-cash.spec.ts`（新增） | 现金单不碰网关、审批通过本地落账、在线支付单仍原路退回 |

现金退款不是「渠道退款成功」，是**登记 + 当面交还**：服务端只落账与回补库存，
不承诺钱已经退了，操作文案必须说清楚，避免店员误以为系统已代付。
