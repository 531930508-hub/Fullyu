# 项目配置说明

## 项目概述

本文档详细说明项目的父工程 mall与核心子工程 mall-admin 的配置管理，重点涵盖 Maven 多模块架构、数据模型关系、依赖管理、构建打包、日志配置及部署运行等关键环节，为开发、测试和生产环境提供完整的配置参考。

## 项目架构

### 工程定位

- **父工程（mall）**：聚合工程，统一管理子模块的公共依赖版本、构建配置和仓库设置，解决版本冲突，简化依赖维护
- **mall-admin 子工程**：后台管理系统核心业务模块，基于 Spring Boot 2.7.5 提供订单管理、权限控制和第三方服务集成等核心功能

### 模块结构

```lua
mall
├── mall-common      # 通用工具类和配置
├── mall-mbg         # MyBatis Generator 代码生成
├── mall-security    # Spring Security + JWT 权限封装
├── mall-admin       # 后台管理系统核心模块
├── mall-search      # Elasticsearch 搜索模块
├── mall-portal      # 商城系统预留模块
└── mall-demo        # 框架测试示例
```

### 环境搭建流程

#### 开发环境配置

1. **源码获取与导入**
   - 克隆项目仓库到本地
   - 使用IDEA导入Maven项目
   - 等待依赖自动下载完成

2. **数据库初始化**
   - 创建MySQL数据库实例
   - 执行SQL初始化脚本
   - 配置数据库连接参数

3. **服务配置**
   
   数据库、redis连接信息等都在配置文件里
   
   ```yaml
   # application.yml 配置
   # application-dev.yml 开发配置
   # application-prod.yml 生产配置
   ```
   
4. **应用启动**
   - 运行 `MallAdminApplication` 主类
   - 默认服务端口：9929

## 配置要点

### 模块依赖关系

- mall-admin 依赖 mall-security
- mall-security 依赖 mall-common
- 确保依赖模块优先编译

### 环境配置要求

- **开发环境**：application-dev.yml
- **生产环境**：application-prod.yml
- 第三方服务密钥正确配置
- 文件目录读写权限充足

## 日志分析要点

- 实时监控应用运行日志
- 关注错误异常堆栈信息
- 定期归档历史日志文件

## 版本兼容性

- 基于JDK 1.8开发
- Spring Boot 2.7.x版本系列
- 支持MySQL 8.0及以上版本
- 适配主流Linux发行版

## 故障排查

### 常见问题解决

1. **依赖下载失败**
   - 检查Maven仓库配置
   - 切换阿里云镜像源
   - 清理本地仓库缓存
2. **服务启动异常**
   - 验证端口占用情况（默认9929）
   - 检查数据库连接配置
   - 确认Redis/RabbitMQ服务状态
3. **第三方服务调用失败**
   - 核对API密钥配置
   - 验证网络连通性
   - 检查服务商接口状态
4. **权限认证问题**
   - 确认JWT令牌配置
   - 验证用户权限设置
   - 检查安全过滤链配置
