# 小程序项目配置说明

## 项目概述

### 项目定位
基于 UniApp + Vue3 构建的微信小程序，使用 HBuilderX 作为开发工具，微信开发者工具进行调试预览，提供完整的前端功能。

## 目录结构

```
full-yu-mini/
├── api/                     # 接口请求模块
├── components/              # 公共组件
├── const/                   # 常量定义
├── filter/                  # 过滤器模块
├── js_sdk/                  # HTTP请求库
├── pages/                   # 页面文件
├── static/                  # 静态资源
├── utils/                   # 工具函数
├── manifest.json            # 应用配置
├── pages.json               # 页面路由
├── tailwind.config.js       # Tailwind配置
└── package.json             # 项目配置
```

## 环境配置

### 环境搭建流程

1. **源码获取与导入**
   - 环境验证
    ```bash
    node --version    # 验证Node.js版本
    npm --version     # 验证npm版本
    ```
   - 依赖安装
    ```bash
    npm install       # 安装项目依赖
    ```
   - 修改配置文件设置后端API地址


2. **环境变量配置**
   - 开发环境
    ```javascript
   export const API_BASE_URL = 'http://localhost:9929';
    ```
   - 生产环境
    ```javascript
   export const API_BASE_URL = 'https://xxx.com/api';
    ```

3. **工具配置**
   - 在 HBuilderX 中打开项目
   - 配置微信开发者工具路径
   - 设置小程序 AppID

## 构建与部署

### 运行管理

#### 开发环境运行

1. **运行到小程序**
   - 选择「运行」->「运行到小程序模拟器」->「微信开发者工具」
   - HBuilderX 自动编译并打开微信开发者工具

2. **真机调试**
   - 连接手机开启USB调试
   - 选择「运行」->「运行到手机或模拟器」

#### 生产构建部署

1. **HBuilderX 发行**
   - 选择「发行」->「小程序-微信」
   - 自动编译生成生产包

2. **微信平台上传**
   - 在微信开发者工具中上传
   - 提交微信审核
   - 发布线上版本

## 功能模块

### 核心业务模块

- **首页**    - 商品推荐、预约和商城快捷入口
- **预约**    - 智能预约、手动预约
- **商城**    - 商品列表、我的卡券、我的礼物
- **我的**    - 微信登录、疗愈记录、收藏技师

### 系统特色功能

- **微信生态**    - 微信登录、聚合支付
- **跨端适配**    - 支持多端发布
- **原子化样式** - Tailwind CSS 高效开发
- **组件化开发** - 可复用组件库

## 注意事项

### 开发注意事项

1. **样式适配**
   - 使用 weapp-tailwindcss 处理样式限制
   - 注意小程序中的 CSS 选择器限制
   - 合理使用 rpx 单位

2. **API 兼容**
   - 使用 UniApp 封装 API
   - 处理平台差异
   - 微信特定功能适配

3. **性能优化**
   - 图片资源压缩
   - 减少包体积
   - 优化首屏加载

### 版本兼容性
- 基于 Vue 3 Composition API
- UniApp 跨端框架支持
- 微信小程序基础库版本要求
- 需要配置合法的微信小程序 AppID

### 开发规范
- 使用 Vue 3 Composition API
- 遵循 UniApp 开发规范
- 采用 Tailwind CSS 原子类
- 组件化开发思想
