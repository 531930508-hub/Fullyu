# 移动端适配规范

> **适用范围**：Full愈 后台管理端 `apps/admin`
> **状态**：v1.0（2026-07-15 起生效）
> **同步文件**：`.qoder/rules/mobile-adaptation.mdc`（AI 规则版）

---

## 一、设计目标

后台管理端需要支持在 PC 与手机上使用。**体验优先度**：

> **能完成工作 > 好看 > 与 PC 一致**

即：手机上可能视觉不如 PC 精致，但**所有功能必须可用**，包括在紧急情况下临时开单、审核、处理场地/课程等。**横竖屏都要能用**。

---

## 二、断点约定

**唯一分界线：768px**

| 屏宽 | 视图 |
|---|---|
| `>= 768px` | PC 视图（含平板横屏），与桌面一致 |
| `< 768px` | 移动端视图（手机竖屏 + 大部分横屏手机） |

在 Vue 组件中判断：

```ts
import { ref, computed, onMounted, onBeforeUnmount } from 'vue'

const windowWidth = ref(window.innerWidth)
const isMobile = computed(() => windowWidth.value < 768)

function onResize() { windowWidth.value = window.innerWidth }
onMounted(() => window.addEventListener('resize', onResize))
onBeforeUnmount(() => window.removeEventListener('resize', onResize))
```

## 三、页面骨架（必须遵循）

所有页面**必须**用统一的 `.page-container` + `.page-header` 结构：

```vue
<template>
  <div class="page-container">
    <div class="page-header">
      <h2 class="page-title">页面标题</h2>
      <a-space>
        <a-button type="primary">新建</a-button>
        <a-button>导出</a-button>
      </a-space>
    </div>
    <!-- 主体内容 -->
  </div>
</template>
```

### ❌ 禁止的写法

```vue
<!-- 错误：内联 style 做布局，媒体查询无法覆盖，窄屏必溢出 -->
<div class="page-header" style="display:flex; justify-content:space-between; align-items:center; margin-bottom:24px">
```

### ✅ 正确做法

```vue
<!-- 直接用 class；.page-header 类在窄屏已自动 flex-wrap -->
<div class="page-header">
```

## 四、组件适配规则

### 4.1 表格 `<a-table>`

```vue
<a-table
  :columns="columns"
  :data-source="rows"
  :scroll="{ x: 'max-content' }"  <!-- 必须：让表格能横向滚动 -->
  :size="'middle'"                 <!-- 手机不用 large -->
/>
```

**Columns 定义要求：**
- 每列显式声明 `width`（数字，单位 px）
- 首列（名称/编号）加 `fixed: 'left'`
- 操作列放最后，加 `fixed: 'right'`

示例：

```ts
const columns = [
  { title: '订单号', dataIndex: 'orderNo', width: 160, fixed: 'left' },
  { title: '会员', dataIndex: 'user', width: 120 },
  { title: '金额', dataIndex: 'amount', width: 100 },
  { title: '状态', dataIndex: 'status', width: 100 },
  { title: '操作', key: 'action', width: 160, fixed: 'right' },
]
```

### 4.2 弹窗 `<a-modal>`

- **不要**显式写 `width="600"`，除非确实需要窄弹窗
- 需要宽版本：`:width="isMobile ? '100%' : 800"` 或用 `width="80%"`
- 全局样式已自动把窄屏 modal 限制为 `calc(100vw - 16px)`
- Modal 内嵌表单**必须**用 `<a-form layout="vertical">`（label 顶部对齐更省宽度）

### 4.3 表单 `<a-form>`

```vue
<!-- ✅ 推荐 -->
<a-form layout="vertical">

<!-- ⚠️ 避免（窄屏会挤成一坨，全局兜底但视觉差） -->
<a-form layout="inline">
```

所有 `a-input / a-select / a-picker` 在窄屏已被全局强制 `width: 100%`，页面无需重复设置。

### 4.4 抽屉 `<a-drawer>`

```vue
<a-drawer
  :width="isMobile ? '100vw' : 500"
  :body-style="{ padding: '16px' }"
/>
```

### 4.5 空间与间距

- 手机上原本 `gap: 24px / margin: 24px / padding: 24px` 视觉太空
- 全局已在 `.page-container` / `.page-header` / `.ant-card-body` 收窄到 `12~16px`
- 页面内**不要**硬编码 `padding: 24px`，用类名 `.page-container` 而不是自己写 style

### 4.6 图片与图集

- 头像/封面窄屏建议不超过 `80×80px`
- 图集横向滚动：`overflow-x: auto`，不要在窄屏用网格硬撑

## 五、数据密集页面（订单/报名/签到）建议

- 手机上**允许**表格横向滚动（比切卡片好，保留排序、批量操作）
- **必须**提供顶部筛选/搜索/日期范围，让用户先缩小数据集
- 分页组件在窄屏已自动换行居中，无需额外处理

---

## 六、触控与安全

- 可点击元素最小 **32×32px**
- Ant Design 默认按钮已达标
- 破坏性操作（删除/取消）**必须**二次确认：`Modal.confirm` 或 `<a-popconfirm>`

---

## 七、提交前自测清单

新增页面/大改造上线前，作者**必须**自测（浏览器开发者工具 → 设备模式）：

- [ ] iPhone SE（375×667）竖屏，页面**无横向滚动条**（表格内滚动除外）
- [ ] iPhone 14 Pro（390×844）竖屏，主要按钮可点、Modal 可关闭
- [ ] iPad Mini（768×1024）竖屏，视图切到 PC 版
- [ ] 横屏手机（667×375），Modal 内容可完整看到并滚动
- [ ] 表格横向滚动时首列/末列 `sticky` 生效
- [ ] 破坏性操作有二次确认
- [ ] 修改密码、退出登录等顶部下拉可点
