# 小程序默认交付清单

> 适用：时叙、在场及后续 Full愈 系微信小程序（uni-app / 原生均可按此裁剪）。  
> 规则：**默认全做**。确实不适用时写“N/A + 原因”，不能留空，也不能等用户提醒。  
> 每项后面的“验收”是证据要求，不是建议。

## 0. 最容易漏的十项

开项前先把这十项写进任务卡，收尾逐项打勾：

- [ ] 右上角转发 + 朋友圈分享（每页注册）
- [ ] 登录前协议勾选、隐私政策、用户协议
- [ ] 公众平台隐私指引声明（手机号/位置/头像/相册写入）
- [ ] 顶部状态栏、胶囊、底部安全区
- [ ] 原生按钮按下灰块与输入框高度
- [ ] 加购/提交/支付的即时反馈与防重复
- [ ] 空、加载、失败、断网、售罄、门店停业
- [ ] 订单生命周期与取消/退款单隔离
- [ ] 字体角色、字号阶梯、字距 token
- [ ] H5 与小程序是否同一版本、同一接口域名

## 2. 导航与真机适配

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 平台判断 | `IS_WEIXIN_MP` 必须用 `#ifdef MP-WEIXIN`，不能靠 `process.env` | 编译产物为 `!0` |
| □ | 状态栏 | 用 `uni.getSystemInfoSync().statusBarHeight` 内联，不依赖 `var(--status-bar-height)` | 真机/开发者工具顶部不压字 |
| □ | 胶囊 | 用 `getMenuButtonBoundingClientRect()` 计算语言切换/工具按钮位置 | 390 与 360 宽均不重叠 |
| □ | 底部安全区 | `min-height` + `padding-bottom: calc(6px + env(safe-area-inset-bottom))`；不要只写 `max()` | 真机 Home 指示条不压按钮 |
| □ | 输入框 | 全局 `input` 显式高度与行高；搜索框单独校验 | 编译产物有高度；真机不被压扁 |
| □ | 原生按钮 | 所有 `<button>` 加 `hover-class="none"`；CSS 兜底透明 | `button` 数与 `hover-class` 数一致，`button-hover` 为 0 |
| □ | 点击区域 | 可点元素 ≥44×44px；图标按钮留足热区 | 真机手指点按不误触 |
| □ | 弹层类型 | 短决策/2–4 选项/确认 → 居中；长列表/表单/键盘 → 底部 | 选店/登录/会员码居中；购物袋/资料底部 |
| □ | 返回 | 子页面有明确返回；悬浮返回需避让状态栏；可选左滑 | 真机从任意子页可回 |
| □ | 滚动 | 切屏/切 tab 滚动归零；弹层打开不带动背景滚动 | 浏览器/真机各测一次 |
| □ | 键盘 | 输入弹层不被键盘遮挡；提交按钮可见 | 真机键盘弹起截图 |
| □ | 横竖屏/小屏 | 至少 390×844 与 360×640 不截断 | 两档截图 |

## 3. 登录、隐私与合规

| □ | 项目 | 默认要求 | 验收 |
|---|---|---|---|
| □ | 协议入口 | 登录前可见《用户协议》《隐私政策》，可打开全文 | 点击可进法务页 |
| □ | 主动勾选 | 复选框默认 false，每次打开重置；未勾选不渲染手机号授权按钮 | 真机/浏览器各一次 |
| □ | 原生隐私 | 不注册 `wx.onNeedPrivacyAuthorization`，保留微信官方隐私弹窗 | 首次调用隐私接口自动弹 |
| □ | 手机号登录 | `open-type="getPhoneNumber"`；code 换手机号；真实模式拒绝显式手机号 | 真机拉起原生面板 |
| □ | 失败语义 | 取消静默；隐私未完成、未开通、过期、频繁分别提示；原始 errMsg 只进日志 | 错误码表 + 手测 |
| □ | 错误映射 | 40029/40163/41008→400；45011→429（一次退避重试）；配置/网络→503 | 单测 + 无效 code 探针 |
| □ | 退出登录 | 只清本地 token/用户态；服务端订单与权益保留；二次确认但外观不刺眼 | 退出后重登可恢复 |
| □ | H5 边界 | H5 不提供手机号登录/真实支付，只提示在小程序内完成 | H5 登录门文案 |
| □ | 隐私指引 | 只声明实际用到的：手机号、位置、头像/昵称、相册（仅写入）；不声明摄像头/相册读取 | 公众平台配置记录 |
| □ | 法务页 | 隐私政策与实际收集字段一致（订单信息、手机号、位置、头像等） | 文案与接口对照 |
| □ | 注销/删除 | 如平台要求或收集了手机号，提供账号注销/数据删除入口或明确客服路径 | 按当期审核规则确认 |
| □ | 审核文案 | 顾客可见处不出现“微信登录/微信手机号”；内部注释可保留 | 产物 grep 为 0 |

|---|---|---|---|

| □ | 支付状态 | 未支付、处理中、已支付、失败、已关闭分开；前端成功不算到账 | 回调/查询后才改状态 |
| □ | 回调 | 验签用原始 rawBody；重复回调幂等；金额/单号校验 | 重放/篡改测试 |

| □ | 退款 | 占用、处理中、成功、失败、未知分开；失败释放；未知保留并重试 | 退款矩阵 |
